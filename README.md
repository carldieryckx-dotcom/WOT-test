# Marketingland 3D

A browsable 3D world of **Marketingland** — the journey from *Diagnosis* through *Strategy* to *Execution*.

Open `index.html` through any static web server (e.g. `python3 -m http.server`) or publish the repo with GitHub Pages. No build step; Three.js loads from a CDN.

## What you can do
- **Explore** – drag to rotate, right-drag to pan, scroll to zoom.
- **Click a numbered pin** (or a stop in the side list) to fly there and read what that stop means.
- **Proper route tour** – visits all 10 stops in order, starting where proper marketers start: Market Orientation.
- **Drive the road** – follow a little car along the road from the hilltop to Brand Beach.
- Keyboard: ← / → step through stops, Esc stops the tour or drive.

## Files
- `index.html` – page shell and UI
- `style.css` – UI styling
- `main.js` – the 3D world (islands, road, buildings, bridges, theme park, beach) and interactions

Based on the Marketingland concept by The Proper Marketing Club (2019).
